# HERO CONTEXT (Elon Leather, cuzdanc.vercel.app)

## Goal
Replace the homepage hero with an interactive canvas hero. A vintage trunk tray holds 4 wallets. The user picks one; it lifts out and opens; an elegant card shows its name and price. Picking another wallet closes the current one (reverse playback), then opens the new one.

## Files (do not rename, do not guess)
- Source clips: public/hero/src/intro.mp4, open_1..open_4.mp4 (wallet N counted from the LEFT in the tray)
- Generated by prepare_hero.sh: public/hero/frames/{desktop,mobile}/{clip}/0001.webp..., public/hero/frames.json
- Idle image = LAST frame of the intro clip. First frame of every open_N clip is meant to look like it (small differences are hidden by a 200 ms crossfade).
- Last frame of each open_N = "opened" pose (wallet centered-left, large, open).

## Player rules (canvas, frame sequences)
- Player state: clip, t (float frame position), dir (+1, -1, 0), speed = fps * rate.
- IDLE: draw idle image. select(j): play open_j forward (t from 0, dir +1).
- If open_i is playing/held and select(j != i): flip dir to -1 (rate 1.5x) and play open_i back to t = 0; then crossfade 200 ms to open_j frame 0 and play forward. select(i) again, Esc, or empty-stage click: reverse to t = 0, crossfade to idle image.
- Latest click wins. Reversing mid-play is just dir = -1 from the current t. No queue.
- At the last frame of open_j: hold. Card appears when t >= 85% of the clip. Card hides the moment reversing starts.
- Draw with fractional t: blend floor(t) and ceil(t) frames using globalAlpha for smooth motion at low fps.
- Rendering: one <canvas>, cover fit on desktop, contain fit on mobile (background = edge colour of idle image), DPR capped at 2, rAF loop only while animating.
- Loading: intro frames first. Then open_1..4 in idle time (a hovered/pressed wallet's clip jumps the queue). If a clip is not fully loaded on click, show a small stitched-ring loader at the wallet and start when ready.
- Expose window.__hero = { state, select(n), close() } for testing.
